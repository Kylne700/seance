The Poltergeist

A ghost with no keys at all, only patience. It reads what a stranger can read and asks one question of the demo payments: were they all sent by the same wallet? It tries four tricks, and one extra, on two ledgers.

The transparent ledger is synthetic. It is not a real chain. This page builds it from the same payments, with the sender, the receiver and the amount written in the open, the way an account ledger does. The times, epoch windows and fees are the real ones. It holds only these payments.

Testnet only. Every transaction here lives on Tari's Esmeralda test network. The demo view keys are public on purpose and unlock nothing else. Never reuse them.
